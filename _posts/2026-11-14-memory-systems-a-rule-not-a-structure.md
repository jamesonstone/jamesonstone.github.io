Maybe the memory system is very simple. Conway's Game of Life works because the rule is tiny and local. The pictures are not in the rule. They come from repeating it. The bitter lesson says the same about learning: the gain is in the iteration, not in a structure designed on top.

The rule here is four verbs: serve, propose, reconcile, dream. The cell is an operation. An operation is a thin wrapper around a generic object. The wrapper gives the object an actionable quality and a toward, and the toward is the current thread. It lives in a small loop, closed and recursive. Lessons, methods, and narrative are not a structure one designs above that loop. They are patterns that survive enough cycles. A glider is only a pattern that persists.

Emergence requires the rule to stay closed. A schema, an ontology, a type hierarchy, or a ranking model bolted on from outside breaks it. A model can live only inside the rule, as its judgment, not as a layer above.

Actionability is what selection acts on. An operation that is never acted on dies. That is how forgetting happens.

What is an operation's neighborhood? If only the current thread decides its fate, the loop is a filter. If co-served operations affect each other, the loop can produce emergence, and a graph can sneak back in.
