This is a philosophical exploration in memory systems. It is one work, published as many short notes, not a set of standalone essays.

Each note takes a single idea as far as it will go and then stops. The series will run as long as the exploration does. Terms will change. Later notes may revise earlier ones.

The question underneath is what a memory system would have to be if it were more than a store: not a file cabinet that retrieves by similarity, but something that faces a direction and withholds what that direction does not need.

Start with [Terms](/blog/2026/11/08/memory-systems-terms.html). That page is a living glossary for the hierarchy — experience, memory, lesson — and for the working vocabulary. Read everything else against it.
