We do not first see objects and then assign them uses. We meet the world as equipment, already in order to something.

Heidegger's hammer is not first a hammer-shaped thing. It is for driving the nail, toward building the house, toward dwelling. That toward is not a story one recites. It is the involvement that makes anything show up as useful at all.

This is the link between perception and narrative, if narrative is kept prospective. An item should appear because it is ready-to-hand for what one is about, not because it resembles the current text. Without a for-the-sake-of-which, nothing is a tool. It is only present-at-hand inventory: a pile of objects.

Similarity search returns objects. A toward returns equipment.

The flattening error is to treat everything perceived as a tool in the same way, at the same time. Equipment shows up inside one involvement, a workshop already oriented. A hammer, a nail, and a storm warning can all be tools, but not toward the same end. If "everything is a tool" becomes one large relevance field, every light in the room has been turned on.

Breakdown belongs here too. The hammer becomes conspicuous when it fails. That is when something withdrawn may interrupt: not because it matched a query, but because the current toward just broke.
