Serve is withholding, not retrieval.

The inventory of memories can be large. The stage cannot. An item is allowed to appear only if the current toward already requires it, including a feeling that is already of this scene. If it does not belong in Chekhov's sense, it is not there.

Dreaming may propose hanging something back up. Reconcile is who approves the set dressing. Serve still only lights what this scene will fire.

The substitution to refuse is search: given a query, return nearby items. Nearby is not the same as required. A system that retrieves well can still dress the stage with unused guns.
