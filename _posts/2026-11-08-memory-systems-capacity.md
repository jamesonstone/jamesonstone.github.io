Computers can store everything. That is not an argument for remembering everything.

A disk can retain every trace. It cannot have them all as memory in the sense used here. Storage without a reason is experience that never became a brick: a complete recording of weather. The human limit is easy to treat as a defect to engineer away. If the machine skips the judgment because space is cheap, the result is not a better memory. It is highly superior autobiographical memory as infrastructure — everything still there, melancholy included — and serve has to fake forgetting after the fact.

The constraint worth copying is not capacity. It is the difference between a trace, a brick, and a lesson. Computers make that an architectural choice rather than a physical one. Capacity is the advantage. Judgment stays provisional.

The raw recording can exist underneath. Serving from it is already the trap.
